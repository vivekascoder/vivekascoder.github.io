## Introduction

The tree method is a way to organize your thoughts/notes in your favorite note taking app, for the sake of this example I’ll be using notion.

Before we begin, I wanna tell you that IDK if something like this already has a name, but it’s just what I’ve started doing, after using PARA for a long time.

The top level page represents the inbox for your mind, everything you are thinking you keep dumping into it, and naturally the topics that emerges you keep adding into this page as a page thus creating a tree like structure.


I find this method better as it’s the easiest and takes no effort in comparison to PARA that requires some thought to where to put your page. In the Tree Method one can mindlessly add stuff to the top page without thinking about where it goes or add top level pages which can be later reorganised if you feel like it, so it gives to flexibility on the effort you wanna put into it.

## Using with Obsidian

Obsidian has been my favorite application for note taking for a while and after jumping between Notion and Obsidian. I've finally decided a while back to pick Obsidian as main driver for Second Brain. Mainly because of suite of tools it offers including Canvas, Bases, Excalidraw and core features like backlinks, graph view to name a few.

In Obsidian to use tree method use I use the following layout:

```
Archives/
Nodes/
Inbox
Index
```

Core idea is to put everything in Inbox (archive when get's too big), after some time, organize data from Inbox i.e create new pages if needed. And then add the appropriate links to the index that categorises the notes in projects, ideas, areas, knowledge.


Inbox is the place where we take notes, and dump ideas, on regulat intervals we archive it improve the index, and clean up inbox. I've also been experimenting with permanent notes where I refactor similar notes of a abstracted topic into a single file that acts as a single source of truth for that topic.
