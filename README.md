# vivekascoder.github.io

This repository contains the source for my personal website built with Zola (a static site generator in Rust).

The site includes a custom theme (themes/archie-zola), content in the `content/` directory and configuration in `config.toml`.

Quick overview
- Static site generator: Zola (https://www.getzola.org)
- Theme: themes/archie-zola
- Content: content/, templates: templates/
- Build output: public/ (generated by `zola build`)

Prerequisites
- Install Zola (see https://www.getzola.org for installation instructions)
- A modern POSIX-like shell to run the included scripts (optional)

Local development
1. Install Zola.
2. From the repository root run:

   zola serve

   This will start a local server and rebuild the site automatically when files change. By default it serves at http://127.0.0.1:1111.

Build for production

- To produce a static site into the `public/` directory:

  zola build

- There is a Vercel build script at `scripts/vercel-build.sh` and a `vercel.json` present if you prefer deploying with Vercel.

Configuration
- Site settings are in `config.toml`. The site URL is configured via `base_url`.
- Content lives under `content/` and follow the Zola front matter format.

Contributing
- Contributions are welcome: open an issue or a PR. Keep changes small and focused.

Notes
- This README is intentionally minimal. See Zola documentation for advanced usage and templating details.
